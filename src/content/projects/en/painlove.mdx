## Architecture

Painlove follows a service-oriented architecture with domain-level bounded contexts.

### Key Design Decisions

- **Event sourcing** for symptom and treatment history to enable full audit trails
- **CQRS** with separate read models for patient vs. practitioner views
- **Offline-first** via local SQLite + conflict-free replicated data types (CRDTs)

### Infrastructure

Deployed on AWS ECS Fargate with RDS PostgreSQL and ElastiCache Redis. CI/CD via GitHub Actions with Terraform-managed infrastructure.
